# Catatan Lanjutan Projek

Projek: Dashboard Aduan Pembinaan Taruna untuk tugas Etos Sandi VI.

Struktur halaman terbaru:
- index.html: pintu masuk pemilihan peran.
- pengadu.html: formulir aduan dan pelacakan progres.
- polisi-taruna.html: dashboard admin polisi taruna, memakai kode akses demo POLTAR2026.
- pengasuh.html: dashboard pengasuh, memakai kode akses demo PENGASUH2026.
- assets/app.css dan assets/app.js: gaya visual dan logika bersama.

Catatan penting:
- Pemisahan peran sudah dibuat pada level halaman dan navigasi.
- Untuk versi statis, kode akses hanya simulasi pembatasan. Untuk keamanan sungguhan perlu backend, akun pengguna, sesi login, dan aturan akses server.
- Data contoh dan data input baru tersimpan di localStorage browser saat aplikasi digunakan.
